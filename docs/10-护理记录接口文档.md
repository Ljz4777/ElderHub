# 护理记录模块接口文档

## 模块概述

护理记录的录入与查询。管理员可查看和删除护理记录；健康管家可录入护理记录并查看自己客户的记录。录入记录时会自动扣减客户对应项目的剩余次数。

- **管理员路径：** `/admin/nurse-record`
- **管家路径：** `/nurse/nurse-record`

---

## 数据模型

### NurseRecord 实体（护理执行记录表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 记录ID |
| customerId | Integer | 客户ID |
| itemId | Integer | 护理项目ID |
| userId | Integer | 执行护理人员ID |
| nursingTime | LocalDateTime | 护理执行时间 |
| nursingContent | String | 本次护理内容 |
| nursingCount | Integer | 本次执行次数 |
| isDeleted | Integer | 逻辑删除 |

### NurseRecordVO 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 记录ID |
| customerId | Integer | 客户ID |
| itemId | Integer | 护理项目ID |
| userId | Integer | 执行护理人员ID |
| nursingName | String | 护理项目名称（关联查询） |
| nursingTime | LocalDateTime | 护理执行时间 |
| nursingContent | String | 护理内容 |
| nursingCount | Integer | 执行次数 |

---

## 一、管理员端

### 1. 查看客户护理记录

- **方法：** `GET`
- **路径：** `/admin/nurse-record/list/{customerId}`

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| customerId | Integer | 客户ID |

### 响应

返回 `List<NurseRecordVO>`，按时间倒序排列。

---

### 2. 删除护理记录（逻辑删除）

- **方法：** `DELETE`
- **路径：** `/admin/nurse-record/remove/{id}`

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 护理记录ID |

---

## 二、管家端

### 3. 录入护理记录

- **方法：** `POST`
- **路径：** `/nurse/nurse-record/save`
- **Content-Type：** `application/json`

### 请求体（NurseRecordAddDTO）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| customerId | Integer | 是 | 客户ID |
| itemId | Integer | 是 | 护理项目ID |
| nursingTime | LocalDateTime | 是 | 护理执行时间 |
| nursingContent | String | 否 | 护理内容描述 |
| nursingCount | Integer | 是 | 本次执行次数 |
| userId | Integer | 否 | 执行人员ID（后端自动填充当前登录管家） |

### 请求示例

```json
{
  "customerId": 5,
  "itemId": 2,
  "nursingTime": "2026-10-10T09:30:00",
  "nursingContent": "完成晨间护理，血压正常",
  "nursingCount": 1
}
```

### 录入业务逻辑（事务）

1. 插入 `nurse_record` 记录（userId = 当前登录管家）
2. 扣减 `customer_nurse_item` 中对应项目的剩余次数：nurseNumber = nurseNumber - nursingCount

---

### 4. 查看客户护理记录

- **方法：** `GET`
- **路径：** `/nurse/nurse-record/list/{customerId}`

### 请求参数

| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| customerId | Path | Integer | 是 | 客户ID |
| userId | Query | Integer | 是 | 当前登录管家ID（后续改为从Token获取） |

### 响应

返回 `List<NurseRecordVO>`。

### 数据隔离规则

管家只能查询自己负责客户的护理记录（customer.userId = 当前管家ID）。
