# 客户护理设置模块接口文档

## 模块概述

为客户设置/移除护理级别、查询客户已购护理项目、项目续费、单独购买项目。

**基础路径：** `/admin/customer`

---

## 数据模型

### CustomerNurseItem 实体（客户已购护理条目表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 条目ID |
| customerId | Integer | 客户ID |
| itemId | Integer | 护理项目ID |
| levelId | Integer | 护理级别ID |
| nurseNumber | Integer | 剩余服务次数 |
| buyTime | LocalDate | 购买日期 |
| maturityTime | LocalDate | 服务到期日期 |
| isDeleted | Integer | 逻辑删除 |

### CustomerNurseItemVO 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 条目ID |
| nursingName | String | 护理项目名称（关联查询） |
| nurseNumber | Integer | 剩余次数 |
| buyTime | LocalDate | 购买日期 |
| maturityTime | LocalDate | 到期日期 |
| status | Integer | 状态（1=正常/未到期 2=欠费/次数≤0 3=已到期） |
| statusMsg | String | 状态描述文本 |
| serialNumber | String | 项目编号 |
| servicePrice | Integer | 服务价格 |

---

## 1. 设置护理级别

- **方法：** `POST`
- **路径：** `/admin/customer/level/set`

### 请求参数

| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| customerId | Body | Integer | 是 | 客户ID |
| levelId | Query | Integer | 是 | 护理级别ID |

### 业务逻辑

1. 校验：客户当前 levelId 必须为 null（未设置过级别）
2. 更新 customer.levelId
3. 批量插入 `customernurseitem`：该级别下所有护理项目
   - buyTime = 当前日期
   - nurseNumber = 1（默认数量）
   - maturityTime = 当前日期 + 3个月

---

## 2. 移除护理级别

- **方法：** `DELETE`
- **路径：** `/admin/customer/level/remove/{customerId}`

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| customerId | Integer | 客户ID |

### 业务逻辑

1. customer.levelId 置为 null
2. 逻辑删除该客户当前级别下所有 `customernurseitem` 记录

---

## 3. 查询客户已购护理项目

- **方法：** `GET`
- **路径：** `/admin/customer/nurse-items/{customerId}`

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| customerId | Integer | 客户ID |

### 响应

返回 `List<CustomerNurseItemVO>`，包含项目名称、剩余次数、购买日期、到期日期及状态。

### 状态判断规则

| 条件 | 状态码 | 描述 |
| --- | --- | --- |
| maturityTime < 当前日期 | 3 | 已到期 |
| nurseNumber ≤ 0 | 2 | 欠费（次数不足） |
| 其他 | 1 | 正常/未到期 |

---

## 4. 项目续费

- **方法：** `POST`
- **路径：** `/admin/customer/nurse-item/renew`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | Integer | 是 | 客户护理条目ID |
| addCount | Integer | 是 | 新增次数 |

### 业务逻辑

- nurseNumber = 原有次数 + 新增次数
- 更新 maturityTime

---

## 5. 移除客户护理项目

- **方法：** `DELETE`
- **路径：** `/admin/customer/nurse-item/remove/{id}`

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 客户护理条目ID |

---

## 6. 单独购买护理项目

- **方法：** `POST`
- **路径：** `/admin/customer/nurse-item/buy`
- **Content-Type：** `application/json`

### 请求体（CustomerNurseItemAddDTO）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| customerId | Integer | 是 | 客户ID |
| itemId | Integer | 是 | 护理项目ID |
| addCount | Integer | 是 | 购买数量 |
| maturityTime | LocalDate | 否 | 自定义到期日期（不传则默认3个月） |

### 请求示例

```json
{
  "customerId": 5,
  "itemId": 2,
  "addCount": 10,
  "maturityTime": "2027-01-10"
}
```
