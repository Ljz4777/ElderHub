# 用户管理模块接口文档

## 模块概述

管理员对系统用户进行管理，包括用户的增删改查、角色列表、菜单树、健康管家列表。

**基础路径：** `/admin/user`（用户）、`/admin/role`（角色）、`/admin/menu`（菜单）

---

## 一、用户管理

### 1. 分页查询用户列表

- **方法：** `GET`
- **路径：** `/admin/user/list`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| nickname | String | 否 | - | 昵称模糊查询 |
| roleId | Integer | 否 | - | 角色ID筛选（1=管理员 2=管家） |
| pageNum | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 10 | 每页条数 |

### 响应数据

返回 MyBatis-Plus `IPage<UserVO>` 分页对象：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| records | List&lt;UserVO&gt; | 当前页数据 |
| total | Long | 总条数 |
| current | Long | 当前页码 |
| size | Long | 每页条数 |

**UserVO 字段：**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 用户ID |
| nickname | String | 昵称 |
| username | String | 登录账号 |
| sex | Integer | 性别（0=女 1=男） |
| email | String | 邮箱 |
| phoneNumber | String | 联系电话 |
| roleId | Integer | 角色ID |
| roleName | String | 角色名称 |
| createTime | LocalDateTime | 创建时间 |
| updateTime | LocalDateTime | 更新时间 |

---

### 2. 查询用户详情

- **方法：** `GET`
- **路径：** `/admin/user/{id}`

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 用户ID |

### 响应

返回 `UserVO` 对象。

---

### 3. 新增用户

- **方法：** `POST`
- **路径：** `/admin/user/save`
- **Content-Type：** `application/json`

### 请求体（UserAddDTO）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| nickname | String | 是 | 昵称 |
| username | String | 是 | 登录账号（唯一） |
| password | String | 是 | 密码 |
| sex | Integer | 否 | 性别（0=女 1=男） |
| email | String | 否 | 邮箱 |
| phoneNumber | String | 否 | 联系电话 |
| roleId | Integer | 是 | 角色ID（1=管理员 2=管家） |

### 请求示例

```json
{
  "nickname": "张管家",
  "username": "nurse01",
  "password": "123456",
  "sex": 1,
  "email": "nurse01@elderhub.com",
  "phoneNumber": "13800138000",
  "roleId": 2
}
```

### 响应

```json
{ "code": 200, "message": "success", "data": null }
```

---

### 4. 修改用户

- **方法：** `PUT`
- **路径：** `/admin/user/update`
- **Content-Type：** `application/json`

### 请求体（UserUpdateDTO）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | Integer | 是 | 用户ID |
| nickname | String | 否 | 昵称 |
| email | String | 否 | 邮箱 |
| phoneNumber | String | 否 | 联系电话 |
| sex | Integer | 否 | 性别 |
| roleId | Integer | 否 | 角色ID |

---

### 5. 删除用户（逻辑删除）

- **方法：** `DELETE`
- **路径：** `/admin/user/remove/{id}`

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 用户ID |

---

### 6. 健康管家列表

- **方法：** `GET`
- **路径：** `/admin/user/nurse-list`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| nickname | String | 否 | 昵称模糊查询 |

### 响应

返回 `List<UserVO>`，仅包含角色为健康管家（roleId=2）的用户。

---

## 二、角色管理

### 7. 角色列表

- **方法：** `GET`
- **路径：** `/admin/role/list`

### 响应

返回 `List<Role>`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 角色ID（1=管理员 2=健康管家） |
| name | String | 角色名称 |

---

## 三、菜单管理

### 8. 菜单树

- **方法：** `GET`
- **路径：** `/admin/menu/tree`

### 响应

返回 `List<Menu>` 菜单树结构：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 菜单ID |
| title | String | 菜单标题 |
| icon | String | 图标 |
| path | String | 路由路径 |
| parentId | Integer | 父菜单ID |
| menusIndex | String | 排序索引 |
