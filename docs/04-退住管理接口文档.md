# 退住管理模块接口文档

## 模块概述

健康管家提交退住申请，管理员审核退住申请。审核通过后根据退住类型处理床位状态。

- **管理员路径：** `/admin/back-down`
- **管家路径：** `/nurse/back-down`

---

## 数据模型

### 退住记录字段（Backdown）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 记录ID |
| customerId | Integer | 客户ID |
| retreatTime | LocalDateTime | 退住时间 |
| retreatType | Integer | 退住类型（0=正常退住 1=死亡退住 2=保留床位） |
| retreatReason | String | 退住原因 |
| auditStatus | Integer | 审批状态（0=已提交 1=同意 2=拒绝） |
| auditPerson | String | 审批人姓名 |
| auditTime | LocalDate | 审批时间 |
| remarks | String | 备注 |
| isDeleted | Integer | 逻辑删除 |

### BackDownVO 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 记录ID |
| customerId | Integer | 客户ID |
| customerName | String | 客户姓名（关联查询） |
| retreatTime | LocalDateTime | 退住时间 |
| retreatType | Integer | 退住类型 |
| retreatReason | String | 退住原因 |
| auditStatus | Integer | 审批状态 |
| auditPerson | String | 审批人 |
| auditTime | LocalDate | 审批时间 |
| remarks | String | 备注 |

---

## 一、管理员端

### 1. 分页查询退住申请列表

- **方法：** `GET`
- **路径：** `/admin/back-down/list`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| pageNum | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 10 | 每页条数 |
| customerName | String | 否 | - | 客户姓名模糊查询 |

### 响应

返回 `PageResult<BackDownVO>` 分页对象。

---

### 2. 审核退住申请

- **方法：** `PUT`
- **路径：** `/admin/back-down/audit`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | Integer | 是 | 退住记录ID |
| auditStatus | Integer | 是 | 审批结果（1=同意 2=拒绝） |
| auditPerson | String | 是 | 审批人姓名 |

### 审核业务逻辑

- 审核通过 + retreatType 为 **正常退住(0) 或 死亡退住(1)** → 当前床位状态改为"空闲"（bedStatus=1）
- 审核通过 + retreatType 为 **保留床位(2)** → 床位状态不变
- 记录审批人、审批时间

---

## 二、管家端

### 3. 提交退住申请

- **方法：** `POST`
- **路径：** `/nurse/back-down/save`
- **Content-Type：** `application/json`

### 请求体（BackDownAddDTO）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| customerId | Integer | 是 | 客户ID |
| retreatTime | LocalDateTime | 否 | 退住时间 |
| retreatType | Integer | 是 | 退住类型（0=正常 1=死亡 2=保留床位） |
| retreatReason | String | 否 | 退住原因 |
| remarks | String | 否 | 备注 |

### 请求示例

```json
{
  "customerId": 5,
  "retreatTime": "2026-10-10T14:00:00",
  "retreatType": 0,
  "retreatReason": "家属接回家照顾",
  "remarks": "无特殊情况"
}
```

---

### 4. 管家查询自己客户的退住申请

- **方法：** `GET`
- **路径：** `/nurse/back-down/list`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| pageNum | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 10 | 每页条数 |
| customerName | String | 否 | - | 客户姓名模糊查询 |
| userId | Integer | 是 | 1 | 当前登录管家ID（后续改为从Token获取） |

### 说明

管家只能查询自己负责客户（customer.userId = 当前管家ID）的退住申请。
