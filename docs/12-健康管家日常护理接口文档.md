# 健康管家日常护理模块接口文档

## 模块概述

健康管家登录后查看自己服务的客户、查看客户护理项目、录入护理记录、查看护理记录。所有接口均遵循数据隔离规则：管家只能操作 `customer.userId = 当前登录管家ID` 的客户。

**基础路径：** `/nurse`

---

## 数据隔离规则

- 所有 `/nurse/**` 接口只操作当前管家负责的客户
- 查询时自动过滤：`customer.userId = 当前登录用户ID`
- 写入时校验客户归属，非自己的客户不能操作
- 目前 userId 通过 `@RequestParam` 传入，后续接入 JWT 拦截器后改为从 Token/UserContext 自动获取

---

## 1. 管家查询自己服务的客户列表

- **方法：** `GET`
- **路径：** `/nurse/customer/list`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| pageNum | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 10 | 每页条数 |
| customerName | String | 否 | - | 客户姓名模糊查询 |
| userId | Integer | 是 | - | 当前登录管家ID |

### 响应

返回 MyBatis-Plus `IPage<Customer>` 分页对象。

---

## 2. 查询客户已购护理项目

- **方法：** `GET`
- **路径：** `/nurse/customer/items/{customerId}`

### 请求参数

| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| customerId | Path | Integer | 是 | 客户ID |
| userId | Query | Integer | 是 | 当前登录管家ID |

### 响应

返回 `List<CustomerNurseItemVO>`，包含项目名称、剩余次数、购买日期、到期日期及状态。

### 项目状态说明

| 状态码 | 描述 | 触发条件 |
| --- | --- | --- |
| 1 | 正常/未到期 | 次数 > 0 且未到期 |
| 2 | 欠费 | nurseNumber ≤ 0 |
| 3 | 已到期 | maturityTime < 当前日期 |

---

## 3. 录入护理记录

- **方法：** `POST`
- **路径：** `/nurse/nurse-record/save`
- **Content-Type：** `application/json`

### 请求参数

| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| dto | Body | NurseRecordAddDTO | 是 | 护理记录信息 |
| userId | Query | Integer | 是 | 当前登录管家ID |

### 请求体（NurseRecordAddDTO）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| customerId | Integer | 是 | 客户ID |
| itemId | Integer | 是 | 护理项目ID |
| nursingTime | LocalDateTime | 是 | 护理执行时间 |
| nursingContent | String | 否 | 护理内容描述 |
| nursingCount | Integer | 是 | 本次执行次数 |

### 业务逻辑（事务）

1. 校验客户归属于当前管家
2. 插入护理记录（userId = 当前管家）
3. 扣减客户该项目剩余次数：nurseNumber = nurseNumber - nursingCount

---

## 4. 查询客户护理记录

- **方法：** `GET`
- **路径：** `/nurse/nurse-record/list/{customerId}`

### 请求参数

| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| customerId | Path | Integer | 是 | 客户ID |
| userId | Query | Integer | 是 | 当前登录管家ID |

### 响应

返回 `List<NurseRecordVO>`，包含护理项目名称、执行时间、内容、次数。

---

## 附录：统一响应格式
