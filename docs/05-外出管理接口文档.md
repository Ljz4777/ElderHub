# 外出管理模块接口文档

## 模块概述

健康管家提交老人外出申请，管理员审核外出申请。审核通过后床位状态变为"外出"；老人回院登记后床位恢复"已入住"。

- **管理员路径：** `/admin/outward`
- **管家路径：** `/nurse/outward`

---

## 数据模型

### 外出记录字段（Outward）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 记录ID |
| customerId | Integer | 客户ID |
| outgoingReason | String | 外出事由 |
| outgoingTime | LocalDateTime | 外出时间 |
| expectedReturnTime | LocalDateTime | 预计回院时间 |
| actualReturnTime | LocalDateTime | 实际回院时间 |
| escorted | String | 陪同人姓名 |
| relation | String | 陪同人与老人关系 |
| escortedTel | String | 陪同人联系电话 |
| auditStatus | Integer | 审批状态（0=已提交 1=同意 2=拒绝） |
| auditPerson | String | 审批人姓名 |
| auditTime | LocalDateTime | 审批时间 |
| remarks | String | 备注 |
| isDeleted | Integer | 逻辑删除 |

### OutwardVO 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| customerId | Integer | 客户ID |
| customerName | String | 客户姓名（关联查询） |
| outgoingReason | String | 外出事由 |
| outgoingTime | LocalDateTime | 外出时间 |
| expectedReturnTime | LocalDateTime | 预计回院时间 |
| actualReturnTime | LocalDateTime | 实际回院时间 |
| escorted | String | 陪同人 |
| relation | String | 与老人关系 |
| escortedTel | String | 陪同人电话 |
| auditStatus | Integer | 审批状态 |
| auditPerson | String | 审批人 |
| auditTime | LocalDateTime | 审批时间 |
| remarks | String | 备注 |

---

## 一、管理员端

### 1. 分页查询外出申请列表

- **方法：** `GET`
- **路径：** `/admin/outward/list`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| pageNum | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 10 | 每页条数 |
| customerName | String | 否 | - | 客户姓名模糊查询 |

### 响应

返回 `PageResult<OutwardVO>` 分页对象。

---

### 2. 审核外出申请

- **方法：** `PUT`
- **路径：** `/admin/outward/audit`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | Integer | 是 | 外出记录ID |
| auditStatus | Integer | 是 | 审批结果（1=同意 2=拒绝） |
| auditPerson | String | 是 | 审批人姓名 |

### 审核业务逻辑

- 审核通过 → 当前床位状态改为"外出"（bedStatus=3）
- 审核拒绝 → 床位状态不变
- 记录审批人、审批时间

---

## 二、管家端

### 3. 提交外出申请

- **方法：** `POST`
- **路径：** `/nurse/outward/save`
- **Content-Type：** `application/json`

### 请求体（OutwardAddDTO）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| customerId | Integer | 是 | 客户ID |
| outgoingReason | String | 是 | 外出事由 |
| outgoingTime | LocalDateTime | 是 | 外出时间 |
| expectedReturnTime | LocalDateTime | 是 | 预计回院时间 |
| escorted | String | 否 | 陪同人姓名 |
| relation | String | 否 | 陪同人与老人关系 |
| escortedTel | String | 否 | 陪同人联系电话 |
| remarks | String | 否 | 备注 |

### 请求示例

```json
{
  "customerId": 5,
  "outgoingReason": "去医院体检",
  "outgoingTime": "2026-10-12T08:00:00",
  "expectedReturnTime": "2026-10-12T17:00:00",
  "escorted": "张小明",
  "relation": "儿子",
  "escortedTel": "13900139000",
  "remarks": "需带医保卡"
}
```

---

### 4. 管家查询自己客户的外出申请

- **方法：** `GET`
- **路径：** `/nurse/outward/list`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| pageNum | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 10 | 每页条数 |
| customerName | String | 否 | - | 客户姓名模糊查询 |
| userId | Integer | 是 | 1 | 当前登录管家ID |

---

### 5. 登记回院

- **方法：** `PUT`
- **路径：** `/nurse/outward/return`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | Integer | 是 | 外出记录ID |

### 业务逻辑

- 记录实际回院时间（后端自动取当前时间）
- 当前床位状态从"外出"恢复为"已入住"（bedStatus=2）
