# 床位管理模块接口文档

## 模块概述

管理员对床位进行统计、查看床位分布示意图、管理床位使用详情、执行床位调换、查询房间和空闲床位。

**基础路径：** `/admin/bed`

---

## 数据模型

### Bed 实体（床位信息表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 床位ID |
| bedNo | String | 床位编号 |
| roomNo | Integer | 所属房间编号 |
| bedStatus | Integer | 床位状态（1=空闲 2=已入住 3=外出） |
| remarks | String | 备注 |

### BedDetails 实体（床位使用详情表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 详情ID |
| bedId | Integer | 床位ID |
| customerId | Integer | 入住客户ID |
| startDate | Date | 入住开始日期 |
| endDate | Date | 退住结束日期 |
| bedDetails | String | 床位详情说明 |
| isDeleted | Integer | 逻辑删除（0=正常 1=删除） |

### Room 实体（房间信息表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 房间ID |
| roomFloor | String | 所在楼层 |
| roomNo | Integer | 房间编号 |

---

## 1. 床位统计

- **方法：** `GET`
- **路径：** `/admin/bed/statistics`

### 响应（BedStatisticsVO）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| totalBeds | Long | 床位总数 |
| freeBeds | Long | 空闲床位数 |
| occupiedBeds | Long | 已入住床位数 |
| awayBeds | Long | 外出床位数 |

### 响应示例

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "totalBeds": 60,
    "freeBeds": 15,
    "occupiedBeds": 40,
    "awayBeds": 5
  }
}
```

## 2. 床位示意图

- **方法：** `GET`
- **路径：** `/admin/bed/map`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| floor | String | 否 | 第一层 | 指定楼层，不传则默认第一层 |

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 房间ID |
| roomFloor | String | 所在楼层 |
| roomNo | Integer | 房间编号 |
| beds | List&lt;BedVO&gt; | 该房间下的床位列表 |

**BedVO：** id、bedNo、roomNo、bedStatus、remarks

## 3. 床位使用详情分页查询

- **方法：** `GET`
- **路径：** `/admin/bed/details/list`

### 请求参数（BedDetailsQuery）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| customerName | String | 否 | - | 客户姓名模糊查询 |
| roomNo | Integer | 否 | - | 房间编号筛选 |
| startDate | Date | 否 | - | 入住日期（格式 yyyy-MM-dd） |
| status | Integer | 否 | 1 | 状态筛选：1=正在使用 2=使用历史 |
| pageNum | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 10 | 每页条数 |

### 状态判断规则

- **正在使用：** is_deleted=0 且（endDate 为空 或 endDate > 当前日期）
- **使用历史：** is_deleted=1 或 endDate ≤ 当前日期

### 响应（PageResult&lt;BedDetailsVO&gt;）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| records | List&lt;BedDetailsVO&gt; | 当前页数据 |
| total | Long | 总条数 |
| pageNum | Long | 当前页码 |
| pageSize | Long | 每页条数 |

**BedDetailsVO：**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 详情ID |
| customerId | Integer | 客户ID |
| customerName | String | 客户姓名（关联查询） |
| bedId | Integer | 床位ID |
| bedNo | String | 床位编号（关联查询） |
| roomNo | Integer | 房间编号（关联查询） |
| startDate | Date | 入住开始日期 |
| endDate | Date | 退住结束日期 |
| bedDetails | String | 床位详情说明 |
| status | Integer | 状态（1=正在使用 2=使用历史） |
| statusMsg | String | 状态描述文本 |

## 4. 修改床位使用详情结束日期

- **方法：** `PUT`
- **路径：** `/admin/bed/details/update`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | Integer | 是 | 详情记录ID |
| endDate | Date | 否 | 结束日期（格式 yyyy-MM-dd），传空表示清除结束日期 |

### 业务逻辑

- 校验结束日期不能早于开始日期

## 5. 床位调换

- **方法：** `POST`
- **路径：** `/admin/bed/transfer`
- **Content-Type：** `application/json`

### 请求体（BedTransferDTO）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| customerId | Integer | 是 | 客户ID |
| oldBedId | Integer | 否 | 旧床位ID（校验与客户当前床位一致） |
| newBedId | Integer | 是 | 目标床位ID |
| bedDetails | String | 否 | 调换说明 |

### 请求示例

```json
{
  "customerId": 5,
  "oldBedId": 3,
  "newBedId": 12,
  "bedDetails": "老人申请调换到朝南房间"
}
```

### 调换业务逻辑（事务）

1. 校验客户存在且已分配床位
2. 校验目标床位存在且状态为"空闲"（bedStatus=1）
3. 校验目标床位 ≠ 当前床位
4. 旧床位使用详情：逻辑删除 + endDate=当天
5. 新建床位使用详情：startDate=当天，endDate=null
6. 旧床位状态改为"空闲"（bedStatus=1）
7. 新床位状态改为"已入住"（bedStatus=2）
8. 更新客户的 roomNo、bedId、buildingNo（固定606）

## 7. 按房间号查空闲床位

- **方法：** `GET`
- **路径：** `/admin/bed/free/{roomNo}`

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| roomNo | Integer | 房间编号 |

### 响应（List&lt;BedVO&gt;）

返回该房间下所有状态为"空闲"的床位列表，按床位编号升序排列。
