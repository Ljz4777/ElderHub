# 登录认证模块接口文档

## 模块概述

提供用户登录、注册、登出功能。登录成功后返回 JWT Token，后续请求需在 Header 中携带 `Authorization: Bearer <token>`。

**基础路径：** `/auth`

---

## 1. 用户注册

### 请求

- **方法：** `POST`
- **路径：** `/auth/register`
- **Content-Type：** `application/json`

### 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | String | 是 | 登录账号 |
| password | String | 是 | 登录密码 |

### 请求示例

```json
{
  "username": "testuser",
  "password": "123456"
}
```

### 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 用户ID |
| username | String | 登录账号 |

### 响应示例

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "username": "testuser"
  }
}
```

---

## 2. 用户登录

### 请求

- **方法：** `POST`
- **路径：** `/auth/login`
- **Content-Type：** `application/json`

### 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | String | 是 | 登录账号 |
| password | String | 是 | 登录密码 |

### 请求示例

```json
{
  "username": "admin",
  "password": "admin123"
}
```

### 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| userId | Integer | 用户ID |
| username | String | 登录账号 |
| token | String | JWT Token |
| role | String | 角色名称（ADMIN / USER） |

### 响应示例

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "userId": 1,
    "username": "admin",
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "role": "ADMIN"
  }
}
```

---

## 3. 用户登出

### 请求

- **方法：** `POST`
- **路径：** `/auth/logout`
- **认证：** 需要登录（`@RequireLogin`）

### 说明

JWT 为无状态认证，服务端不保存 Token。登出只需前端清除本地 Token 即可，接口仅返回成功状态。

### 响应

```json
{
  "code": 200,
  "message": "success",
  "data": null
}
```

---

## 统一响应格式

```json
{
  "code": 200,        // 200=成功，500=失败
  "message": "success",
  "data": {}          // 业务数据，失败时为 null
}
```
