# 客户管理模块接口文档

## 模块概述

管理员对在住客户（老人）进行入住登记、修改、删除、外出/回院操作，以及查询无管家客户列表。

**基础路径：** `/admin/customer`

---

## 客户实体字段（Customer）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 客户ID |
| customerName | String | 老人姓名 |
| customerAge | Integer | 年龄 |
| customerSex | Integer | 性别（0=男 1=女） |
| idcard | String | 身份证号 |
| roomNo | String | 房间号 |
| buildingNo | String | 所属楼栋（固定606） |
| bedId | Integer | 床位ID |
| checkinDate | Date | 入住日期 |
| expirationDate | Date | 合同到期日期 |
| contactTel | String | 联系电话 |
| birthday | LocalDate | 出生日期 |
| height | String | 身高 |
| weight | String | 体重 |
| bloodType | String | 血型 |
| psychosomaticState | String | 身心状况描述 |
| attention | String | 护理注意事项 |
| filepath | String | 头像文件路径 |
| isDeleted | Integer | 逻辑删除（0=正常 1=删除） |

---

## 1. 入住登记

- **方法：** `POST`
- **路径：** `/admin/customer/save`
- **Content-Type：** `application/json`

### 业务逻辑

1. 校验合同到期日期 ≥ 入住日期
2. 年龄由出生日期自动计算
3. 楼栋号固定为 606
4. 插入客户记录
5. 关联床位状态更新为"已入住"
6. 插入床位使用详情记录（startDate=入住日期，endDate=null）

### 请求体（Customer）

传入完整客户信息，关键字段：customerName、customerSex、idcard、roomNo、bedId、checkinDate、expirationDate、contactTel、birthday 等。

### 请求示例

```json
{
  "customerName": "张大爷",
  "customerSex": 0,
  "idcard": "410701195001011234",
  "roomNo": "301",
  "bedId": 5,
  "checkinDate": "2026-01-15",
  "expirationDate": "2027-01-14",
  "contactTel": "13900139000",
  "birthday": "1950-01-01",
  "bloodType": "A型",
  "attention": "高血压，需按时服药"
}
```

### 响应

```json
{ "code": 200, "message": "success", "data": null }
```

---

## 2. 修改客户

- **方法：** `PUT`
- **路径：** `/admin/customer/update`
- **Content-Type：** `application/json`

### 业务逻辑

- 若合同到期日期变更，同步更新当前生效床位使用详情的 endDate

### 请求体

传入完整 Customer 对象（必须包含 id）。

---

## 3. 删除客户（逻辑删除）

- **方法：** `DELETE`
- **路径：** `/admin/customer/remove/{id}`

### 业务逻辑（级联）

1. 客户逻辑删除（is_deleted=1）
2. 当前床位状态改为"空闲"（bedStatus=1）
3. 当前生效床位使用详情逻辑删除

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 客户ID |

---

## 4. 老人外出

- **方法：** `POST`
- **路径：** `/admin/customer/goOut/{id}`

### 说明

将客户当前床位状态改为"外出"（bedStatus=3）。

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 客户ID |

---

## 5. 老人回院

- **方法：** `POST`
- **路径：** `/admin/customer/comeback/{id}`

### 说明

将客户当前床位状态改回"已入住"（bedStatus=2）。

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 客户ID |

---

## 6. 无管家客户列表

- **方法：** `GET`
- **路径：** `/admin/customer/no-nurse`

### 说明

查询尚未分配健康管家的客户列表（userId=-1 的客户），用于管家分配功能。

### 响应

返回 `List<Customer>`。
