# 护理级别管理模块接口文档

## 模块概述

管理员管理护理级别（如一级护理、二级护理），并为每个级别配置包含的护理项目。

**基础路径：** `/admin/nurse-level`

---

## 数据模型

### NurseLevel 实体（护理级别表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 主键ID |
| levelName | String | 级别名称（如：一级护理、二级护理） |
| levelStatus | Integer | 级别状态（1=启用 2=停用） |
| isDeleted | Integer | 逻辑删除 |
| createTime | Date | 创建时间 |
| updateTime | Date | 更新时间 |

---

## 1. 分页查询护理级别

- **方法：** `GET`
- **路径：** `/admin/nurse-level/list`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| pageNum | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 10 | 每页条数 |
| levelStatus | Integer | 否 | - | 级别状态筛选（1=启用 2=停用） |

### 响应

返回 MyBatis-Plus `IPage<NurseLevel>` 分页对象。

---

## 2. 新增护理级别

- **方法：** `POST`
- **路径：** `/admin/nurse-level/save`
- **Content-Type：** `application/json`

### 请求体（NurseLevel）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| levelName | String | 是 | 级别名称（唯一） |
| levelStatus | Integer | 否 | 状态，默认1=启用 |

### 请求示例

```json
{
  "levelName": "三级护理",
  "levelStatus": 1
}
```

---

## 3. 修改级别状态

- **方法：** `PUT`
- **路径：** `/admin/nurse-level/update-status`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | Integer | 是 | 级别ID |
| levelStatus | Integer | 是 | 目标状态（1=启用 2=停用） |

---

## 4. 查询某级别下配置的护理项目

- **方法：** `GET`
- **路径：** `/admin/nurse-level/items/{levelId}`

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| levelId | Integer | 级别ID |

### 响应

返回 `List<NurseContent>`，即该级别关联的所有护理项目列表。

---

## 5. 给级别添加护理项目

- **方法：** `POST`
- **路径：** `/admin/nurse-level/item/save`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| levelId | Integer | 是 | 级别ID |
| itemId | Integer | 是 | 护理项目ID |

### 业务逻辑

在 `nurselevelitem` 关联表中插入一条记录，将项目关联到该级别。

---

## 6. 从级别移除护理项目

- **方法：** `DELETE`
- **路径：** `/admin/nurse-level/item/remove/{levelId}/{itemId}`

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| levelId | Integer | 级别ID |
| itemId | Integer | 护理项目ID |

### 业务逻辑

删除 `nurselevelitem` 关联表中对应的记录。
