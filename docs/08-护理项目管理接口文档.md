# 护理项目管理模块接口文档

## 模块概述

管理员维护护理项目库，包括项目的增删改查、状态管理。护理项目是护理服务的最小单元（如晨间护理、口腔护理）。

**基础路径：** `/admin/nurse-content`

---

## 数据模型

### NurseContent 实体（护理项目表）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 主键ID |
| serialNumber | String | 项目编号（如 HL001） |
| nursingName | String | 护理项目名称 |
| servicePrice | Integer | 服务价格（单位：元） |
| message | String | 项目描述 |
| status | Integer | 项目状态（1=启用 2=停用） |
| executionCycle | String | 执行周期（如：每日、每周） |
| executionTimes | String | 执行次数（如：1次/天） |
| isDeleted | Integer | 逻辑删除 |
| createTime | Date | 创建时间 |
| updateTime | Date | 更新时间 |

---

## 1. 分页查询护理项目

- **方法：** `GET`
- **路径：** `/admin/nurse-content/list`

### 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| pageNum | Integer | 否 | 1 | 页码 |
| pageSize | Integer | 否 | 10 | 每页条数 |
| status | Integer | 否 | - | 项目状态筛选（1=启用 2=停用） |
| nursingName | String | 否 | - | 项目名称模糊查询 |

### 响应

返回 MyBatis-Plus `IPage<NurseContent>` 分页对象。

---

## 2. 新增护理项目

- **方法：** `POST`
- **路径：** `/admin/nurse-content/save`
- **Content-Type：** `application/json`

### 请求体（NurseContent）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| serialNumber | String | 是 | 项目编号（唯一） |
| nursingName | String | 是 | 项目名称 |
| servicePrice | Integer | 否 | 服务价格 |
| message | String | 否 | 项目描述 |
| status | Integer | 否 | 状态，默认1=启用 |
| executionCycle | String | 否 | 执行周期 |
| executionTimes | String | 否 | 执行次数 |

### 请求示例

```json
{
  "serialNumber": "HL001",
  "nursingName": "晨间护理",
  "servicePrice": 30,
  "message": "协助老人起床、洗漱、整理床铺",
  "status": 1,
  "executionCycle": "每日",
  "executionTimes": "1次/天"
}
```

---

## 3. 修改护理项目

- **方法：** `PUT`
- **路径：** `/admin/nurse-content/update`
- **Content-Type：** `application/json`

### 请求体

传入完整 NurseContent 对象（必须包含 id）。

### 停用业务逻辑

- 状态改为"停用"(2) 时，自动从 `nurselevelitem` 关联表中删除该项目的关联记录
- **不影响**客户已购买的 `customernurseitem` 记录

---

## 4. 删除护理项目（逻辑删除）

- **方法：** `DELETE`
- **路径：** `/admin/nurse-content/remove/{id}`

### 路径参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 项目ID |

### 删除业务逻辑

1. 先删除 `nurselevelitem` 中该项目的所有关联记录
2. 再对 `nursecontent` 执行逻辑删除（is_deleted=1）
3. **不影响**客户已有的 `customernurseitem` 记录
